## E. Phase 1 実装時に追加した仮仕様（2026-11-27）
| # | 内容 | 仮仕様（変更は設定またはマイグレーションで可能） |
|---|---|---|
| E1 | 呼び出し中のまま残った通話（ブラウザ終了・通信断） | 呼び出し中のまま 2 分経過で自動的に「失敗」扱い。通話中のまま残ったものは、次の発信時に画面から「前の通話を終了」できる |
| E2 | 画面を開いている間に許諾撤回・架電禁止になった顧客 | 発信時にサーバーで再確認し、理由を画面に表示して発信しない（担当も自動解除） |
| E3 | 架電ルール・架電結果マスタの変更権限 | システム管理者のみ変更可。PM は閲覧のみ（権限マトリクス上は PM も「設定」だが、DB 側を管理者に限定） |
| E4 | 架電結果マスタで画面から変えられる範囲 | 表示名・ショートカット・並び順・使用有無のみ。結果の追加や自動処理の変更はマイグレーションで行う |
| E5 | MFA 必須設定・通話録音の有効化 | 画面からは変更不可（セキュリティ設定のため） |
| E6 | ユーザー追加 | 管理者が招待メールを送り、本人がパスワードを設定。招待（Supabase Auth Admin API）のみ service_role を使用 |
| E7 | KPI の集計方式 | Phase 1 はリアルタイム集計（25 万件・30 日で約 0.14 秒）。日次集計テーブル（P1-KPI-02）は件数増加時に導入 |
| E8 | 面談実施率の定義 | 期間内に予定日がある面談のうち「実施済み」の割合（獲得日ベースではない） |
| E9 | 1 時間あたり架電数の稼働時間 | 担当者×日ごとの「最初の架電〜最後の架電」の合計（勤怠連携は未実装） |
| E10 | 操作ログの対象 | ユーザー・ロール・チーム・目標・スクリプト・架電ルール・結果マスタの変更、架電禁止の登録/解除、利用許諾の一括登録、CSV 出力。最終ログイン日時のみの更新は記録しない |
