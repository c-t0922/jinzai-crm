# 11. 想定運用コスト（概算）

> **注意**：2026年時点の公開価格の記憶に基づく概算です。契約前に各社の最新料金を必ず確認してください。為替は 1 USD = 150 円で計算。
> 人件費・開発費・kintone 既存費用は含みません。

## 1. 前提（初期想定【仮】）
- 利用者 30 名（うち架電担当 15 名）、Vercel の開発者席 2 名
- 架電：15 名 × 120 件/日 × 20 日 = **月 36,000 発信**、接続率 25%、平均通話 3 分 → 通話 約 27,000 分/月（留守電等の短時間接続を含む）
- データ：顧客 25万件 → 将来 100万件、通話ログ 年 40万件超、録音 有効化時 月 約 27,000 分

## 2. 月額費用（概算）

| 項目 | プラン・内訳 | 月額目安 |
|---|---|---|
| Vercel | Pro（2 席 × $20）＋超過分 | 約 6,000〜15,000 円 |
| Supabase（本番） | Pro $25 ＋ Compute 増強（Small〜Medium 想定）＋ PITR アドオン | 約 15,000〜40,000 円 |
| Supabase（staging/dev） | 小規模プロジェクト | 約 4,000〜8,000 円 |
| CTI（Twilio 例） | 日本の電話番号（数番号）＋ 発信通話料（携帯宛は固定宛より高額）＋ ブラウザ接続料 | **約 40〜80 万円**（通話 27,000 分の場合） |
| 録音保存 | Twilio 録音保存 or Supabase Storage（3分≒1〜3MB） | 約 2,000〜10,000 円 |
| メール送信 | Resend / SendGrid 等 | 0〜3,000 円 |
| エラー監視 | Sentry Team 等 | 約 4,000 円 |
| ドメイン | 年額を月割 | 数百円 |
| **合計（CTI除く）** | | **約 3〜8 万円** |
| **合計（CTI込み）** | | **約 45〜90 万円** |

- **最大のコスト要因は通話料**です。架電件数・接続時間に比例します。国内の定額制クラウドCTI（席課金型）は 1 席 月 5,000〜15,000 円程度のサービスもあり、15 席で 7.5〜22.5 万円＋通話料（かけ放題プランの有無）になります。
  → CTI は Phase 2 前に **Twilio と国内CTI数社の見積比較**を推奨（本システムはアダプタ設計のため切替可能）。
- Phase 4 の AI 文字起こし・要約を全通話に適用すると、27,000 分/月で 数万〜十数万円程度の追加を想定。

## 3. 初期費用
| 項目 | 目安 |
|---|---|
| 電話番号取得・本人確認 | 数千円 |
| 負荷試験用 staging の一時的な増強 | 1〜3 万円（試験期間のみ） |
| ヘッドセット（15 台） | 1 台 5,000〜15,000 円 |

## 4. コスト最適化方針
- 集計はキャッシュテーブル化し DB の Compute を抑える。
- 録音は保管期限（例 90 日【仮】）を設定し自動削除。
- 不通系の再架電上限を設定し、無駄な発信を減らす。
